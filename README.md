# 스마트 음성 추적 프롬프터 (Smart Voice-Tracking Teleprompter)

강사가 원고를 소리 내어 읽으면 브라우저의 Web Speech API를 통해 실시간으로 발화를 감지하여, 읽는 속도에 맞춰 끊김 없이 유려하게 올라가는 방송국형 스마트 웹 프롬프터입니다.

🌐 **온라인 웹 바로가기**: [https://jwlee5499-netizen.github.io/smart-teleprompter/](https://jwlee5499-netizen.github.io/smart-teleprompter/)

---

## 🌟 주요 특징 및 기능

1. **🎙️ 화자 속도 예측 기반 연속 유체 스크롤 (Predictive Continuous Scroll)**
   - 강사가 실제로 말을 시작할 때까지 혼자 스크롤되지 않고 대기합니다 (`첫 발화 감지`).
   - 단어가 띄엄띄엄 인식되더라도 뚝뚝 끊기지 않고, **강사의 평소 읽는 속도(px/sec)를 실시간 추정하여 전동 컨베이어 벨트처럼 부드럽고 일정하게 글이 상승**합니다.
   - 아직 읽지 않은 다음 줄은 가이드라인 위로 절대 먼저 넘어가지 않도록 안전 상한선(`Safe Ceiling`)을 유지합니다.

2. **🎬 NG 대처 및 한 문장 되감기 (←)**
   - 강사가 읽다가 실수를 했을 때 **왼쪽 화살표(`←`)**를 누르면 정확히 한 문장 위로 부드럽게 되돌아가며, 다시 읽기 시작할 때까지 대기합니다.

3. **🖱️ 마우스 클릭 & 휠로 시작 위치 지정**
   - 마우스를 원하는 문장 위에 올리면 `여기서부터 시작` 배지가 표시되며, 클릭 한 번으로 해당 문장을 가이드라인에 맞추고 그 위치부터 바로 시작할 수 있습니다.

4. **🎨 토크형 대본 출연자별 폰트 컬러 & 실시간 미리보기**
   - 대담·토크형 촬영을 위해 대본 편집기에서 `{노랑}`, `{하늘}`, `{초록}`, `{핑크}`, `{주황}` 태그를 1클릭으로 삽입할 수 있습니다.
   - 편집 화면 우측의 **실시간 컬러 미리보기**와 프롬프터 화면에서 화자 배지(`[진행자]`, `[출연자A]`) 및 지정된 글자 색상이 깔끔하게 렌더링됩니다.

5. **🎯 읽는 가이드라인 및 방해 요소 자동 숨김**
   - 시선 높이에 맞춰 가이드라인 위치를 화면 상단 기준 **15% ~ 65%** 범위에서 자유롭게 조절할 수 있습니다.
   - 스크롤이 시작되면 가이드라인의 작은 글씨 버튼들이 **자동으로 투명하게 숨겨져 대본 글씨를 전혀 가리지 않습니다.**

6. **📑 대본 챕터 목차 퀵 점프**
   - 대본에 `# 1. 오프닝` 형태로 챕터를 작성하면 우측 상단 챕터 서랍에서 원하는 파트로 원클릭 이동할 수 있습니다.

7. **🔤 초대형 폰트 (최대 160px) & 거울 반전 모드 (Mirror Mode)**
   - 원거리 모니터용 대형 폰트 지원 및 전문 방송용 하드웨어 프롬프터(반사 유리)를 위한 좌우/상하 반전을 원클릭 지원합니다.

## ⌨️ 단축키 안내

프롬프터 화면에서 다음 단축키를 사용할 수 있습니다:

| 단축키 | 기능 설명 |
| :--- | :--- |
| **Spacebar (스페이스바)** | 재생 / 일시정지 |
| **↓ (아래 화살표)** | 스크롤 속도 빨라짐 (+5) |
| **↑ (위 화살표)** | 스크롤 속도 느려짐 (-5) |
| **← (왼쪽 화살표) / Z / Backspace** | **NG 발생 시 한 문장 위로 되감기** |
| **→ (오른쪽 화살표) / X** | 다음 문장으로 건너뛰기 |
| **R** | 대본 맨 처음 위치로 리셋 |
| **ESC** | 대본 편집 화면으로 돌아가기 |
| **원하는 문장 마우스 클릭** | 클릭한 문장 위치부터 시작 |

## 🚀 실행 및 배포 방법

### 방법 1. 웹 브라우저에서 바로 사용 (별도 설치 불필요)
- [GitHub Pages 배포 사이트](https://jwlee5499-netizen.github.io/smart-teleprompter/)에 접속하여 즉시 사용할 수 있습니다.

### 방법 2. 로컬 PC 무설치 실행 (오프라인 / 스튜디오)
- **`무설치_실행하기.bat`** 또는 **`실행하기.bat`**을 더블 클릭합니다.
- Node.js가 설치되어 있지 않은 환경에서도 로컬 서버(`http://localhost:5180`)가 즉시 구동됩니다.

### 방법 3. 개발자 모드
```bash
npm install
npm run dev
```

## 💡 음성 인식 권장 환경
- **권장 브라우저**: Google Chrome 또는 Microsoft Edge (Web Speech API 지원 브라우저)
- **마이크 권한**: 브라우저 상단에서 요청하는 마이크 사용 권한을 `허용`해 주세요.
