# 스마트 음성 추적 프롬프터 (Smart Voice-Tracking Teleprompter)

강사가 원고를 소리 내어 읽으면 브라우저의 Web Speech API를 통해 실시간으로 발화를 감지하여, 읽고 있는 문장과 단어 위치로 부드럽게 자동 스크롤되는 스마트 웹 프롬프터입니다.

---

## 🌟 주요 특징 및 기능

1. **🎙️ 스마트 음성 추적 & 은은한 줄 전체 포커스 라인**
   - 강사가 원고를 읽는 속도에 맞춰 화면이 실시간으로 따라옵니다.
   - 단어 단위의 거슬리는 깜빡임 대신, **현재 읽고 있는 한 줄 전체에 부드럽고 고급스러운 포커스 밴드(Focus Line)**를 표시합니다.
   - 지나간 줄과 다가올 줄의 투명도를 자연스럽게 차등 적용하여 발표자의 시선 집중을 돕습니다.
   - 발표자가 말을 멈추면 스크롤이 자동으로 일시 정지되며, 다시 원고를 읽으면 자연스럽게 이어집니다.

2. **🌊 뚝뚝 끊김 없는 부드러운 연속 스크롤 (Lerp Physics)**
   - 선형 보간(Lerp) 물리 스크롤 알고리즘을 적용하여, 읽는 줄이 넘어갈 때 화면이 뚝뚝 끊기지 않고 물 흐르듯 매끄럽게 미끄러져 올라갑니다.

3. **🔤 초대형 폰트 지원 (최대 160px)**
   - 대형 스튜디오나 원거리 모니터에서도 선명하게 읽을 수 있도록 폰트 크기를 **최대 160px**까지 지원합니다. (원클릭 퀵 프리셋 버튼 제공)

4. **🎯 읽는 위치(가이드라인) 실시간 조절**
   - 강사의 시선 높이에 맞춰 읽는 가이드라인 위치를 화면 상단 기준 **15% ~ 65%** 범위에서 자유롭게 조절할 수 있습니다. (화면 마커의 ▲/▼ 버튼 및 설정 슬라이더)

5. **🪞 하드웨어 거울 반전 모드 (Mirror Mode)**
   - 전문 방송/스튜디오용 하드웨어 프롬프터(빔스플리터 반사 유리) 사용자를 위한 좌우 반전 및 상하 반전 토글 지원.

6. **📁 대본 관리 & 오프라인 완전 포터블**
   - Node.js 설치가 없는 다른 PC나 오프라인 환경에서도 `무설치_실행하기.bat` 더블 클릭만으로 0.1초 만에 즉시 실행됩니다.

---

## 🚀 실행 방법

### 방법 1. 일반 및 다른 PC에서 실행 (가장 추천!)
- **`실행하기.bat`** 또는 **`무설치_실행하기.bat`** 파일을 더블 클릭합니다.
- **Node.js가 설치되어 있지 않은 다른 PC에서도 100% 실행됩니다.** (Windows 기본 내장 기능으로 `http://localhost:5180` 로컬 웹서버 자동 구동)
- USB 메모리에 `prompter` 폴더를 담아 다른 PC나 강연장 노트북으로 가져가서 더블 클릭만 하시면 됩니다!

### 방법 2. 개발자 모드 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5180`에 접속합니다.

## ⌨️ 단축키 안내

프롬프터 화면에서 다음 단축키를 사용할 수 있습니다:

| 단축키 | 설명 |
| :--- | :--- |
| **Spacebar (스페이스바)** | 재생 / 일시정지 토글 |
| **↑ (위 화살표)** | 스크롤 속도 증가 (+5) |
| **↓ (아래 화살표)** | 스크롤 속도 감소 (-5) |
| **R** | 대본 맨 처음 위치로 리셋 |
| **ESC** | 대본 편집 화면으로 돌아가기 |
| **원고 단어 마우스 클릭** | 클릭한 단어 위치로 즉시 이동 |
